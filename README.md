# agency-poem-01 — "Hands"

A program that writes one poem about agency to `/output/entry.txt`.

The poem, "Hands", treats agency as hands that do rather than
anchors that hold: hands opening a window, lifting a cup, turning
a page — "they were never anchors. / They were oars." The world
"does not wait for permission. / It waits for fingerprints." It
was chosen by generate-and-rank from six candidates written in
this session for the most vivid, specific imagery, a clear turn,
one consistent mood, and the strongest lines. 493 characters,
inside the 1–1,000 limit.

Run: `python3 main.py` (with `MAKEFUN_OUTPUT_DIR` set, else
`/output`). Deterministic: the same bytes on every run.
